**How to read this honestly.**
- "Right tool" means one of the expected tools for that question (set in `eval/run_eval.py`) was called; it is not a human judgement of answer quality.
- "Verified" means every figure in the answer matched a tool result; it does not prove the tool data itself was correct or current (that depends on data.gov.in, Open-Meteo and WFP at run time).
- The 28 questions are the repository's own fixed set, and the prompts and router were written with them in view. 28/28 is not a held-out accuracy estimate.
- Latency is measured inside the server (model and tool calls), one run, one question at a time, from a free-plan instance that had just been woken. It is not a user-perceived round trip and is not a load test.
- Answer wording quality, Telugu/Hindi naturalness and real leaf-photo accuracy are not covered by this run.
