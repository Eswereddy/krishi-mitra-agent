Optional built-in research documents (plain .txt files). Each file starts with two header lines:

    Title: <document title>
    Source: <URL or citation>

then the text. Only add documents whose licence lets you redistribute them, and only text copied exactly from the source. The app ships with NONE: farmers and judges can upload their own ICAR / state agriculture university PDFs inside the app (they stay on the phone; the server keeps nothing).
