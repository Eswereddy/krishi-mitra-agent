# API reference

Generated by `scripts/gen_api_docs.py` from the running FastAPI app. All endpoints are JSON unless noted. No accounts: farmer data lives on the device; the endpoints below are stateless. Rate limits are per IP per minute (env `RATE_AGENT_PER_MIN`, `RATE_VOICE_PER_MIN`). Interactive docs: `/docs` on a running server.

## Errors

- `400` invalid or missing input (for example `consent.share_details` absent on `/api/case/build`).
- `429` rate limit. `502` model service error or timeout (friendly message, no stack trace). `503` model key not configured.
- Tool and data failures are returned as `{"error": ...}` inside the result and shown to the farmer honestly; they never crash a request.
